Pusat Bantuan

1. Cara Mendapatkan Gemini API Key

Aplikasi ini memproses transkrip Anda secara otomatis melalui kecerdasan buatan Google (Gemini AI). Anda memerlukan kunci (API Key) gratis untuk menggunakannya:

  1. Buka halaman Google AI Studio.
  2. Login menggunakan akun Google pribadi Anda.
  3. Klik tombol biru "Create API key" di layar.
  4. Salin (Copy) kode yang muncul (terdiri dari huruf & angka panjang).
  5. Tempel (Paste) kode tersebut ke kotak pencarian di pojok kanan atas aplikasi ini.

Data Anda Aman: Kunci API tidak disimpan di server manapun. Sistem hanya menyimpannya secara lokal di browser Anda (Local Storage) agar Anda tidak perlu memasukkannya berulang kali.

2. Bagaimana AI Mengkonversi Nilai?

Model AI bekerja selayaknya Tim Evaluator Manusia dengan melakukan 4 tahapan berurutan saat Anda menekan tombol "Generasi Dokumen":

Pemindaian OCR

AI mengekstraksi data visual dari ijazah/transkrip secara cerdas. AI bisa mendeteksi nama siswa, sekolah asal, dan membaca tabel mata pelajaran meskipun formatnya berantakan.

Deteksi Kurikulum

Berdasarkan nama negara dan angka yang tertera, AI mengenali sistem nilai asal. Apakah itu GPA (4.0), Persentase (100%), Skala Huruf (A-F), atau Skala khusus (1-10) seperti di Belanda/Eropa.

Konversi & Translasi

Nomenklatur asing diterjemahkan ke standar Indonesia (Math → Matematika). Nilai asli disetarakan menggunakan perhitungan proporsional ke rentang nilai 0 hingga 100.

Validasi Resmi

AI secara otomatis memberikan predikat nilai (Sangat Baik / Baik / Cukup) dan menyusun 1 paragraf narasi evaluasi resmi yang siap cetak untuk Surat Keterangan.
